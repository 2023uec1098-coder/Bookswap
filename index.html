📚 BookSwap

Exchange Books. Save Money.

BookSwap is a college book exchange and marketplace prototype where students can list, search and request academic books.

Project Workflow

Login → List Book → Browse → View Details → Send Request → Accept/Reject → Complete Exchange

Why BookSwap?

📖 List Books

Students can add books they no longer need.

🔎 Search

Find books by title, author, subject or semester.

🤝 Exchange

Send requests and coordinate a book exchange.
